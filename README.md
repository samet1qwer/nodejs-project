# 📌 Portfolio Website (Node.js + Admin Panel)

This project is a personal portfolio website.  
Both the **frontend (user side)** and the **admin panel interface** are built using **ready-made templates**,  
while the backend is developed with **Node.js (Express.js)**.

The website consists of a public-facing portfolio page and an **admin panel** where all content can be managed.

---

## 🚀 Technologies Used

- Node.js
- Express.js
- MongoDB & Mongoose
- EJS (Template Engine)
- Express Session
- HTML / CSS / JavaScript
- Bootstrap
- MVC Architecture

## ▶️ Installation & Run

1. Clone the repository  
   git clone https://github.com/username/project-name.git

2. Go to the project directory  
   cd project-name

3. Install dependencies  
   npm install

4. Start the application  
   npm start

Note: MongoDB must be running.
